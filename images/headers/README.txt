Header images
=============

Drop your banner photos in this folder with these exact names:

  home.jpg          -> Home page (tall banner)
  about.jpg         -> About page
  team.jpg          -> Team page
  publications.jpg  -> Publications page
  blog.jpg          -> Blog page (and blog posts without their own image)
  gallery.jpg       -> Gallery page

Tips
- Landscape photos work best, ideally at least 1920 px wide.
- Keep each file under ~500 KB so the pages load quickly (export as JPG at ~75-80% quality).
- The left side of the image sits under the text and gets darkened, so photos where
  the interesting part is centre/right look best.
- To use a different filename or format (e.g. .png), change the
  background-image: url('images/headers/...') line near the top of that page's .html file.
- If an image is missing, the banner just shows a plain dark background.
