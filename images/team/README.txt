Team headshots
==============

1. Save each person's photo in this folder, e.g.  images/team/matthew-smith.jpg
   (Use lowercase and hyphens, no spaces.)

2. In data/team.json, put just the filename in that person's "photo" field:

     "photo": "matthew-smith.jpg",

   Leave it as "" if there's no photo yet; a plain grey circle is shown instead.

Tips
- Photos are shown as small circles, so square, head-and-shoulders crops work best,
  with the face roughly centred.
- 400 x 400 px is plenty. Keep each file under ~100 KB.
